# Rockson Performance — Schedule App

A personal trainer schedule builder. Create, manage, and export weekly training schedules as PDFs for clients.

---

## Quick start (first time)

```bash
git clone <repo-url>
cd rockson-schedule
chmod +x install.sh
./install.sh
```

The install script will:
- Install all system and Python dependencies
- Set up the database automatically
- Create a `start.sh` shortcut
- Optionally configure auto-start on boot

Then open **http://localhost:5002** in your browser.

## Starting the app (after installation)

```bash
./start.sh
```

## Features

- **Client management** — add clients, view all their schedules by week
- **Schedule builder** — define training days, add exercises per day with sets/reps/notes/images
- **Exercise library** — shared library of exercises with muscle group tagging; upload images
- **Templates** — save any schedule as a reusable template; duplicate previous weeks
- **Weekly volume** — live set count per muscle group, updates as you build
- **PDF export** — dark or light mode, one page per training day, includes volume overview

## Folder structure

```
rockson/
├── app.py              # Flask backend + all API routes
├── schema.sql          # Database schema and seed data
├── requirements.txt    # Python dependencies
├── install.sh          # One-command setup script
├── start.sh            # Generated by install.sh
├── instance/
│   └── rockson.db      # SQLite database (auto-created)
├── static/
│   └── images/
│       ├── exercises/  # Exercise and uploaded images
│       └── pt_logo.*   # Uploaded PT logo
└── templates/
    └── index.html      # Full frontend (single file)
```

## Updating

```bash
git pull
./venv/bin/pip install -r requirements.txt -q
# Restart the app
sudo systemctl restart rockson-schedule   # if using systemd
# or just re-run ./start.sh
```

## Port

The app runs on port **5002** by default. To change it, edit the last line of `app.py`:
```python
app.run(host='0.0.0.0', port=5002, debug=False)
```

## Backup

Your data lives entirely in `instance/rockson.db`. Copy this file to back up everything.

```bash
cp instance/rockson.db instance/rockson_backup_$(date +%Y%m%d).db
```
